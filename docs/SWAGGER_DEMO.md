# Руководство по Swagger UI — Retro-Streamer

* **Адрес документации:** `http://localhost:8000/docs`
* **Префикс всех эндпоинтов:** `/api/v1`

---

## Шаг 1. Регистрация нового пользователя
1. Найдите и раскройте эндпоинт `POST /api/v1/auth/register`.
2. Нажмите **Try it out**.
3. Заполните JSON в поле `Request body` тестовыми данными.
4. Нажмите синюю кнопку **Execute**.

---

## Шаг 2. Глобальная авторизация (Замочек) 🔐
1. Прокрутите страницу Swagger UI в самый верх.
2. В правом верхнем углу нажмите кнопку **Authorize** со значком открытого замочка 🔓.
3. В открывшемся окне заполните поля:
   * **Client credentials location:** выберите **`Request body`**.
   * **username:** введите зарегистрированный email.
   * **password:** введите пароль.
   * Поля *client_id* и *client_secret* оставьте пустыми.
4. Нажмите кнопку **Authorize** внутри модального окна, затем нажмите **Close**.

---

## Шаг 3. Получение информации об игре
1. Найдите и раскройте эндпоинт `GET /api/v1/game/info/{game_name}`.
2. Нажмите **Try it out**.
3. Заполните параметры запроса:
   * **game_name**: укажите `snake`, `2048`, `labyrinth` или `sokoban`.
   * **seed**: введите любое число (например, `42`).
4. Нажмите синюю кнопку **Execute**.

---

## Шаг 4. Запуск генерации GIF-прохождения 
1. Найдите и раскройте эндпоинт `POST /api/v1/game/render`.
2. Нажмите **Try it out**.
3. В поле **`game_name`** тела запроса выберите или введите название игры строго строчными буквами (`snake`, `sokoban`, `game2048` или `labyrinth`).
4. После того как Swagger UI динамически отобразит поля для выбранной игры, заполните массив шагов (`steps`) тестовыми данными.
5. Нажмите **Execute**.
6. Из тела ответа скопируйте полученный идентификатор задачи (`task_id`).

---

## Шаг 5. Проверка статуса задачи и просмотр результата 
1. Найдите и раскройте эндпоинт `GET /api/v1/game/tasks/{task_id}`.
2. Нажмите **Try it out**.
3. Вставьте скопированный ранее UUID в поле **task_id**.
4. Нажмите **Execute**.
5. Дождитесь завершения задачи и кликните прямо по ссылке из поля **`download_url`** (она сразу сформирована через `localhost:9000`), чтобы открыть или скачать сгенерированный GIF-файл.

---

## Шаг 6. Проверка таблицы лидеров
1. Найдите и раскройте эндпоинт `GET /api/v1/leaderboard/{game_name}`.
2. Нажмите **Try it out**.
3. Задайте имя игры в параметре **game_name** (например, `snake`).
3. Задайте ID сезона в параметре **season_id** (например, `1`).
3. Задайте seed в параметре **seed** (например, `42`).
4. Нажмите **Execute** для проверки формирования топа игроков.
